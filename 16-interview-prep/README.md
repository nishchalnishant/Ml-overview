# Interview Hub

This is the canonical entry point for interview prep in this repo.

Use this folder first when you want a clean route instead of jumping between overlapping note sets.
It is the drill layer, not the deep-dive layer.

## How This Repo Is Organized

- `03-classical-ml`, `05-deep-learning-core`, `10-llms`, `11-llm-applications`, `13-production-ml`, and `15-system-design` are the **canonical learning layers**.
- `16-interview-prep` is the **rehearsal layer**: it compresses those deep dives into interview answers, tradeoffs, and checklists.
- When something feels repeated, the rule is simple: **deep dive in the topic folder, rapid recall in `16-interview-prep`**.
